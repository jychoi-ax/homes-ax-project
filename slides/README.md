# Slides

이 디렉터리는 AX 프로젝트 발표 자료 원본을 관리한다.

원칙:

- `docs/`는 기술 백서 원본이다.
- `slides/`는 발표 자료 원본이다.
- 발표 자료는 백서 내용을 요약/재구성한 파생 산출물일 수 있다.
- 발표 자료 수정이 필요하면 가능하면 관련 백서와 함께 정합을 확인한다.
